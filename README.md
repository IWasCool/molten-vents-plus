# Molten Vents Plus

Renewable resource and oil vents for **Minecraft 1.21.1 / NeoForge**, built around Create.

Water vents produce impure stone, molten vents produce regular ore stone, and superheated vents produce pure stone. Includes renewable oil, Ponder tutorials, and JEI/EMI support.

**Requires:** NeoForge 21.1.251+, Create 6.0.10+, and [Create: Molten Vents 2.1.1+](https://github.com/Apothicon02/Create-Molten-Vents). Mod version: **0.0.1**.

**Languages:** all 143 Minecraft language options have complete files: 120 initial translations and regional variants; 23 rare or fictional options use English fallback. Translation corrections are welcome.

**Build:** JDK 21, then `./gradlew build` or `gradlew.bat build`.
